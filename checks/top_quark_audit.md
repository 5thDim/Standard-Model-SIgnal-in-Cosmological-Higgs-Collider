# Top Quark Signal 检查记录

本次检查针对工作区现有 PDF 及其同名 TeX 源码，也检查了 `checks/` 中已有脚本，并对照 `Gauge Boson Signal.tex` 的 box 因子化和角度约定。修改保留了开始检查时尚未提交的工作区内容。

结论：在恒定质量、精确 de Sitter、零化学势、轻 Higgs 外腿和 collapsed 展开的范围内，原文的传播子、Bose 抵消、软动量幂次与五个角系数的结构通过了检查；硬线积分脚本存在一个实际归一化错误，原文因此不能算已经完成振幅的可靠求值。现已修正，并补出可直接计算的有限硬线系数。这里的验证针对因子化的领先非解析项，不等同于对未展开完整 box 的直接数值积分。

## 实际错误与修正

1. **硬线 seed 的超几何归一化错误。** `weyl_scalar_seed.py` 把参考文献 Eq. (92) 中的 regularized `3F2` 当作普通 `3F2`，漏除了 `Gamma(d) Gamma(e)`。归一化见 [Qin–Xianyu, Eq. (138)](https://arxiv.org/html/2301.07047v1#A1.E138)。这会改变振幅；原脚本的实质量共轭检查无法发现它。新增独立 conformal-scalar 检验：在 `lambda=-i/2, p=q=0`，直接时间积分给出同支 `-3/16`、异支 `1/32`，修正后吻合。另检查了不等时间幂和 folded 导数。
2. **“延拓不稳定”的原因判断不充分。** 修正归一化后，利用标量核的 `lambda -> -lambda` 对称性，将每个同支 seed 写成收敛 balance 为 `1+i mu` 的表达式。三个调节参数路径均趋向相同结果。正文撤下了原先把不稳定归因于物理复质量延拓障碍的表述。
3. **反向线的 Fourier 共轭记号混用。** 原式将“Fourier 系数的伴随”和“伴随场的 Fourier 变换”写成了同一记号，和前文的动量 delta 约定不一致。改用坐标空间 Grassmann 恒等式，再明确反向线的 Fourier 系数为 `-R(-k;t',t)`。这不改变后文实际使用的传播子矩阵。

## 补齐的推导

- SK 求和先于端点极限。单支中的双极点乘上 `2(cos(pi delta)-1)` 留下有限项，不能直接逐支丢弃。其贡献为
  `-E = -pi^2 2^(-1-2i mu) [Gamma(1+2i mu)/Gamma(1+i mu)]^2`。
- 用五个收敛的普通 `3F2(1)` 给出 `P1, P2`。原来的形式性双重无穷级数被替换为有限特殊函数表达式，减少了中间模式系数、积分区域和延拓符号。
- 给出 `P2` 的 bootstrap 源项和端点有限项；硬线动量导数不是只对 Gamma 因子求导。
- 写出 SK 被积函数在较晚端点出现 `E_+(x)-E_-(x) = -2i x^3/3 + O(x^5)` 的抵消。
- 明确从自然比值 `ks^2/(kL kR)` 改为 gauge-boson 文稿的 `ks^2/(4 k12 k34)` 时产生 `16^(2i mu)` 的相位，和两个 Bose 求和及 Pauli trace 一起核对最终归一化。
- 补齐 mixed seed 的一般分部积分关系、实性证明和数值求值。

## 物理与计算结论

| 检查项 | 结果 |
|---|---|
| 两个不同 Weyl 场描述 Dirac top | 正确；无 Majorana `1/2`，颜色仅计 `Nc=3` 一次 |
| 共形重标度 | `t=a^(3/2)t_cov` 后每个 Yukawa 顶点保留一个 `a`，正确 |
| 模函数 | 一阶场方程、归一化、负频模式和等时完备关系均通过 |
| 有符号 SK 收缩 | `R^< = -vv†` 及两种非局域 Wightman 收缩相等通过检验 |
| 图计数 | 六个有向 box，其中四个有 s-channel 双软切割；不应额外再乘 2 或 4 |
| 精确动量路由 | 代表图右侧硬线是 `q+ks+k3`；本阶计算必须保留 `ks` |
| 最低阶 clock | `ks^(3±4i mu)` 在四个切割图求和后抵消 |
| 首个存活 clock | `ks^(5±4i mu)`，需要每端的一阶硬动量展开及软线 descendants |
| 五个角系数 | 原代数形式保留，含 `A3=-3 A2`；替换为修正后的硬系数求值 |
| mixed 项 | 非振荡 `ks^3`，它对软动量分量非解析，不是可随意丢弃的接触项 |
| 量纲、符号和相位 | 四点函数去除 delta 后量纲 `-5`；闭合费米子环负号和比值相位通过检查 |

恒定 `h0` 和无质量 Higgs 并非自动兼容。正文现在明确需要背景变化足够慢、重整化后的 Higgs 有效质量远小于 `H^2`。此处计算的是连接的 `delta h` 四点函数，尚需指定 Higgs 到曲率扰动的转化，才能得到观测用的曲率 trispectrum。

与 gauge-boson 文稿采用相同的步骤：双软切割 → 左右硬子图 → 自旋/偏振收缩 → 标量 `F0` 卷积 → 五角结构。区别是 top 的零阶硬块会抵消，不能把向量计算中的零阶硬线替换直接用于这里。对照时也注意到 gauge 文稿展示的 box 路由在右硬线略去了 `ks`；这仅适用于其领先软极限，不能作为 top 一阶展开的精确路由。本次未改动 gauge 文件。

## 数值与可复现检查

例如 `mu=0.73`：

- `P1 = -1.598130708346613 - 2.346219693837161 i`
- `P2 =  1.923885008554568 + 1.958596830655767 i`
- mixed `H11 = -1.388500280198814`

正文还列出 `mu=0.2,1,2,5`。实现位于 `weyl_scalar_seed.py`：`hard_coefficients()` 返回 `P1,P2,H21,H11`；`clock_angular_coefficients()` 返回 `A1,A2,A3,B1,D1`；`mixed_hard_seed()` 对完整 SK 求和后的 mixed seed 作四阶外推。

在项目根目录运行：

```bash
python3 checks/weyl_signal_checks.py
python3 checks/weyl_hard_expansion_check.py
python3 checks/weyl_seed_checks.py
```

已有代数、模函数和硬动量展开检查通过。新增测试对照 conformal-scalar 的独立初等积分，检查复质量核的阶数反射、实质量 seed 的反射、`mu=0.2,0.73,2,5` 的工作精度稳定性、三个共同 regulator 路径、完整 clock 归一化及 mixed 项的步长/精度稳定性。具体残差见 `weyl_signal_checks.txt` 和 `weyl_seed_checks.txt`。

检验证明的是上述近似内的领先非解析振幅。完整未展开 box 的多重振荡积分、解析接触项的重整化、变化中的 Higgs 背景、非零化学势以及转为曲率相关函数不在这组结果中；不能据此宣称全动量四点函数已被数值验证。
